# A-Level Atlas
为中文学习者和国际课程教师制作的课程知识图谱与练习。可以免费在线试用，也可以下载到本地备课、授课或自学。

[在线打开 A-Level Atlas](https://phytnesskun.github.io/A-Level-Atlas/) · [下载离线包](https://github.com/phytnesskun/A-Level-Atlas/raw/refs/heads/main/downloads/A-Level-Atlas-trial-0.1.0.zip) · [反馈问题或建议](https://github.com/phytnesskun/A-Level-Atlas/issues/new)

**六科图谱。** 选择 CAIE 或 Pearson Edexcel、学段与学科，查看数学、进阶数学、物理、化学、生物与经济的知识关系。有多条选考路线的数学课程保留模块信息。图谱覆盖 26 个资格，包含 976 个知识节点。默认显示教师已确认的依据，待审关系可另行查看。各资格采用各自标注的考纲版本。

**六题试用。** Cambridge International AS & A Level Physics 9702，2025–2027 考纲 Version 2，§§19.1–19.2。六条目标各配一道原创选择题。可以直接选“我不确定”，也可以先选一个答案，再标记对这个选项不确定。完成后能查看反馈和本机的作答记录。选择题可以观察方法辨认，独立推导还需要看学生的推导过程。

**离线使用。** 解压整个 ZIP 后打开最外层的 `index.html`，保留目录结构。两张考试局总图和六道题均可离线打开；提交反馈需要联网。若使用浏览器临时模式，关窗后可能清除作答记录。

反馈时请写下科目、目标编号、遇到的步骤和预期结果。例如“9702 §19.2.1，我看懂了图线，但不明白反馈里的面积指哪一块”。GitHub Issues 为公开讨论，请省略学生姓名和个人档案。

本仓提供免费试用发行包，适用范围见[使用说明](USAGE.md)。这是独立教学项目。
