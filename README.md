# A-Level Atlas
为中文学习者和国际课程教师制作的课程知识图谱与练习。可以免费在线试用，也可以下载到本地备课、授课或自学。

[在线打开 A-Level Atlas](https://phytnesskun.github.io/A-Level-Atlas/) · [下载离线包](https://github.com/phytnesskun/A-Level-Atlas/raw/refs/heads/main/downloads/A-Level-Atlas-trial-0.4.0.zip) · [反馈问题或建议](https://github.com/phytnesskun/A-Level-Atlas/issues/new)

**第一次带班试用**　[直接打开 Motion Graphs 第 3 题](https://phytnesskun.github.io/A-Level-Atlas/?v=0.4.0#motion-3)。预留约 10 分钟，先让学生自己做，再看「回顾我的作答」核对他的想法。该题支持看着原图分步求助，答对原题后可选一张新图无提示复测。可把题号、版本、设备和遇到的步骤交给老师统一反馈。

**六科图谱。** 选择 CAIE 或 Pearson Edexcel、学段与学科，查看数学、进阶数学、物理、化学、生物与经济的知识关系。有多条选考路线的数学课程保留模块信息。图谱覆盖 26 个资格，包含 976 个知识节点。默认显示教师已确认的依据，待审关系可另行查看。各资格采用各自标注的考纲版本。

**可试用专题。** 每组约 8–12 分钟，21 道原创选择题可从首页或图谱中对应的学习目标进入。

| 专题 | 课程与依据 | 题数 |

| [Motion Graphs](https://phytnesskun.github.io/A-Level-Atlas/#motion-1) | CAIE AS Physics 9702 · 同版 §2.1，PDF p.17 | 4 |

题干用英文，点击「查看中文题意」可看翻译。选择「我不确定」会留在本题，从一个小问题开始。答错或看了讲解还有疑问，可以往前查一个更基础的步骤。能用这个方法后再回原题重答；仍卡住时，页面会记下可以请老师一起看的具体问题。「回顾我的作答」保留每步选择、讲解和原题订正。点「反馈这道题」会自动带上课程和题号。

**离线使用。** 解压整个 ZIP 后打开最外层的 `index.html`，保留目录结构。两张考试局总图和四组练习均可离线打开；提交反馈需要联网。若使用浏览器临时模式，关窗后可能清除作答记录。

**部署试用站。** [下载 0.4.0 静态网站托管 ZIP](https://phytnesskun.github.io/A-Level-Atlas/downloads/A-Level-Atlas-static-site-0.4.0.zip)。根目录的 `index.html` 是网站首页。练习、交互图谱和两张可点击的考试局总图都从部署站点加载；网页上的「离线包（GitHub）」链接到官方发行地址。热铁盒网页托管和花生壳 Drop 均支持上传站点压缩包。上传时保留完整目录，网站首页指向根目录的 `index.html`，无需运行构建命令。部署后可在首页地址末尾加上 `#motion-3` 试做原图追问，并点一次「下载离线包」。 [热铁盒托管说明](https://host-intro.retiehe.com/) · [花生壳 Drop](https://drop.ficp.fun/)

反馈时请写下科目、目标编号、遇到的步骤和预期结果。例如“9702 §19.2.1，我看懂了图线，但不明白反馈里的面积指哪一块”。GitHub Issues 为公开讨论，请省略学生姓名和个人档案。
