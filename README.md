# A-Level Atlas
为中文学习者和国际课程教师制作的课程知识图谱与练习。可以免费在线试用，也可以下载到本地备课、授课或自学。

[在线打开 A-Level Atlas](https://phytnesskun.github.io/A-Level-Atlas/) · [下载 0.4.0-r4 离线试用包](https://phytnesskun.github.io/A-Level-Atlas/downloads/A-Level-Atlas-trial-0.4.0-r4.zip) · [反馈问题或建议](https://phytnesskun.github.io/A-Level-Atlas/#share-feedback)

**第一次带班试用**　[直接打开 Motion Graphs 第 3 题](https://phytnesskun.github.io/A-Level-Atlas/?v=0.4.0#motion-3)。预留约 10 分钟，先让学生自己做，再看「回顾我的作答」核对他的想法。该题支持看着原图分步求助，答对原题后可选一张新图无提示复测。可把题号、版本、设备和遇到的步骤交给老师统一反馈。

**查一个学习目标。** 选择学科、考试局和阶段，从课程目录进入目标。首个带完整试用流程的目标是 CAIE AS Physics 9702 §2.1.4「从位移–时间图的斜率求速度」。目标页可以直接试做 Motion Graphs 第 3 题。学生在题内求助时可以查看当前步骤所需的基础，再回到同一道题继续。图谱涵盖数学、进阶数学、物理、化学、生物与经济的知识关系。有多条选考路线的数学课程保留模块信息。图谱覆盖 26 个资格，包含 976 个知识节点。默认显示教师已确认的依据，待审关系可另行查看。各资格采用各自标注的考纲版本。

**课程设计样品。** [数学与物理推荐授课大纲 · 独立演示](https://phytnesskun.github.io/A-Level-Atlas/demos/teaching-plans/) 展示怎样把两点斜率放在运动图之前，以及选修 FP3 时怎样安排叉乘的先修知识。可比较四种考试局组合的衔接重点和两种学制的适用条件。

**学生练习。** 四组共 21 道原创选择题，每组约 8–12 分钟。可以在首页选择专题进入练习，也可以从图谱中对应的学习目标直接打开题目。

题干用英文，点击「查看中文题意」可看翻译。选择「我不确定」会留在本题，从一个小问题开始。答错或看了讲解还有疑问，可以往前查一个更基础的步骤。Motion Graphs 第 3 题会继续显示同一张图，说明为什么先查这一步。点「回到原题，自己再试」即可重答。仍卡住时，页面会记下可以请老师一起看的具体问题。「回顾我的作答」保留每步选择、讲解和原题订正。点「反馈这道题」会自动带上课程和题号。

**第一次离线试用**　完整解压 ZIP，先读最外层的 `README.txt`，再用浏览器打开同一层的 `index.html`。首页可查学习目标或直接做一道题，两局高清总图保留在首页。从「教师备课」可打开双语授课案例、带班指南，从「学生练习」可进入四组练习，再查看回顾或重置本组。六科图谱、案例、答题及复制反馈都可离线使用；把复制的内容发送给老师或提交 GitHub Issues 时需要联网。

**部署试用站。** [下载 0.4.0-r4 静态网站托管 ZIP](https://phytnesskun.github.io/A-Level-Atlas/downloads/A-Level-Atlas-static-site-0.4.0-r4.zip)。根目录的 `index.html` 是网站首页。练习、交互图谱和两张可点击的考试局总图都从部署站点加载；网页的「下载离线包」链接到官方发行地址。热铁盒网页托管和花生壳 Drop 均支持上传站点压缩包。上传时保留完整目录，网站首页指向根目录的 `index.html`，无需运行构建命令。部署后可在首页地址末尾加上 `#motion-3` 试做原图追问，并点一次「下载离线包」。 [热铁盒托管说明](https://host-intro.retiehe.com/) · [花生壳 Drop](https://drop.ficp.fun/)

反馈时请写下科目、目标编号、遇到的步骤和预期结果。例如“9702 §19.2.1，我看懂了图线，但不明白反馈里的面积指哪一块”。GitHub Issues 为公开讨论，请省略学生姓名和个人档案。
